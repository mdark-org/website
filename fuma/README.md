# fuma

This application uses TanStack Start and Fumadocs on Cloudflare Workers.
Content and navigation come from D1. Markdown is compiled on the server and
rendered from its HAST tree during SSR and client navigation.

## Run locally

From the workspace root:

```bash
pnpm install --frozen-lockfile
pnpm --filter fuma dev
```

Open http://localhost:3000. Configure bindings in `cloudflare.config.ts` and
provide local secrets in `.env.development`. The local D1 database must contain
the schema in `drizzle/d1` and a published source snapshot.

`BASE_URL`, `SPONSOR_URL`, and `NEXT_PUBLIC_GAID` are public build inputs.
Vite exposes only these values to the client as `VITE_BASE_URL`,
`VITE_SPONSOR_URL`, and `VITE_GAID`. Server credentials remain Workers bindings.

Set `CLOUDFLARE_PERSIST_TO` to use a separate local storage directory.
Set `CLOUDFLARE_REMOTE_BINDINGS=false` to disable remote bindings for offline checks.

`src/routeTree.gen.ts` is generated by the TanStack Start Vite plugin.
Run `dev` or `build` after adding routes.

## Build and deploy

```bash
pnpm --filter fuma build
pnpm --filter fuma start
pnpm --filter fuma deploy:development
pnpm --filter fuma deploy:production
```

Deployments use the existing `cf` configuration, D1, R2, AI Search, and Workflows.
The build output is `.cloudflare/output/v0`. Production deployment reads
`.secret.production`. Development deployment reads `.secret.development`.

The application renders D1 content on demand. The Vinext response-store
integration and Next.js ISR settings are removed. No content is fetched from
D1 at build time, and no document prerendering is configured.

Production deployments configure an hourly Cron Trigger (`7 * * * *`, at minute 7
of every hour in UTC). The scheduled handler creates a sync run and starts the
existing full-sync Workflow, which publishes content and then updates the search
index. Development and preview deployments do not configure a schedule. The
schedule takes effect after production deployment; Cloudflare may take up to
15 minutes to propagate Cron Trigger changes.
